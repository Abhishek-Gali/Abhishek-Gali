### 🛡️ Engineering Focus & Capabilities

I engineer deterministic systems at the intersection of **defensive cybersecurity, systems infrastructure, and autonomous agent orchestration**. My work focuses on replacing fragile scripts with production-grade runtimes:

- **Zero-Trust Identity & Agent Authorization:** Enforcing strict boundary isolation, cryptographic identity delegation, and taint analysis for tool-calling agents to prevent Indirect Prompt Injection (IPI).
- **High-Throughput Network Telemetry:** Inspecting layer 4–7 socket and packet streams, measuring packet drop rates, and evaluating systems-level observability.
- **Contract-Aware Security Auditing:** Building asynchronous dynamic scanners that ingest OpenAPI/JSON schemas for deterministic surface auditing.
- **Game Engine Systems:** Designing deterministic 2D state machines, collision layers, and viewport camera interpolations in Godot.
